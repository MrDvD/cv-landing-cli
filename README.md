# Admin CLI для страницы-резюме

🚧 **Проект находится в разработке** 🚧

CLI приложение для управления данными CV/резюме через REST API. Инструмент предоставляет интерактивный интерфейс для добавления и управления активностями, проектами, образованием и событиями.

## Описание

Admin CLI для страницы-резюме — это командная утилита, написанная на Go, которая позволяет:

- Добавлять новые активности (проекты, образование, события)
- Интерактивно заполнять формы через терминальный интерфейс
- Отправлять данные в REST API для хранения
- Управлять тегами и вложениями

## Особенности

- Красивый TUI (Terminal User Interface) с использованием Bubble Tea
- Интерактивные формы с различными типами полей (текст, дата, выбор)
- Интеграция с REST API
- Быстрые команды CLI для автоматизации

## Технологии

- **Go 1.25** - основной язык
- **Cobra** - CLI фреймворк
- **Bubble Tea** - TUI фреймворк
- **HTTP клиент** - для работы с REST API

## Установка

### Из исходного кода

```bash
git clone <repository-url>
cd cv-landing-cli
go build -o cv-landing-cli
```

### Требования

- Go 1.25+

## Конфигурация

Настройки API находятся в файле `assets/config.json`:

```json
{
  "activityApiBase": "http://your.domain:4040/v1/activity/",
  "tagsApiBase": "http://your.domain:4040/v1/tags/",
  "attachmentsApiBase": "http://your.domain:4040/v1/attachments/"
}
```

## API

Приложение взаимодействует с REST API для сохранения данных. Поддерживаемые эндпоинты:

- `POST /v1/activity/` - создание активности
- `GET /v1/activity/` - получение всех активностей
- API для тегов и вложений (в разработке)
